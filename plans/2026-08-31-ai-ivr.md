# AI-Powered IVR Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn `deploy/agentcore_aws_lambda` into a deployable AI IVR — a local wizard page collects a business prompt, intents, and a destination per intent; `make deploy` produces the AgentCore runtime plus a published Studio flow with ConversationRelay and the intent handoffs wired up.

**Architecture:** A Twilio number points at a Studio flow. The flow fetches an AgentCore presigned WebSocket URL from a new Lambda `/session` route, runs a ConversationRelay widget against it, then splits on the `HandoffData` slug the agent returns and dials the matching destination. The agent is the existing Strands-on-AgentCore setup with a generated system prompt and one `transfer_call` tool that sets `session.pending_handoff_data`.

**Tech Stack:** Python 3.10+ (Pydantic v2, FastAPI, Strands, `twilio` SDK, `httpx`), TypeScript AWS CDK, vanilla HTML/CSS/JS with no build step, `uv` for Python deps, `pytest`.

**Design spec:** `specs/2026-08-31-ai-ivr-design.md`. Read it before starting.

> Plan location note: this lives in `plans/` rather than `docs/superpowers/plans/`, because
> `docs/` is the published MkDocs site (`mkdocs.yml` has an explicit `nav`) and an internal
> plan placed there would be built and published alongside the API reference. This mirrors
> the spec, which lives in `specs/` for the same reason.

## Global Constraints

- **Python 3.10+.** Use `from __future__ import annotations` in every new module so `X | None` syntax works on 3.10.
- **No changes to `src/tac_aws/`.** Everything in this plan lives under `deploy/agentcore_aws_lambda/` and `tests/ivr/`. If you believe a library change is needed, stop and raise it.
- **Ruff, line length 100.** CI runs `uv run ruff check .` and `uv run ruff format --check .` over the *whole* repo including `deploy/`. Every task ends ruff-clean.
- **mypy scope is unchanged** (`src/tac_aws` and `getting_started` only). Write fully typed code anyway; do not add `deploy/` to the mypy invocation.
- **Tests live in `tests/ivr/`** because root `pytest` config has `testpaths = ["tests"]`. Nothing else is collected.
- **Never import `agent/main.py` from a test.** It calls Secrets Manager at import time.
- **Imports from TAC use the `tac` package** (`from tac.models.handoff import PendingHandoffData`), never internal `tac_aws` paths. See `CLAUDE.md`.
- **The canonical config model is `agent/ivr_config.py`.** The wizard and the Studio generator import it by putting `agent/` on `sys.path`. Do not duplicate the model. (This refines the spec, which sketched a separate `wizard/models.py`; one definition is the point.)
- **`handoffData` is a bare slug** (`billing`), never JSON. Studio's `split-based-on` compares with equality.
- **Reserved intent key:** `fallback`. No configured intent may use it.
- **Secrets never land in git.** `ivr-config.json`, `agent/ivr-config.json`, and `.env` are gitignored.

```python
"""IVR configuration model and loader.

Canonical home for the schema shared by three consumers: the AgentCore agent
bundle (which builds its prompt and tool from it), the local wizard (which
writes it), and the Studio flow generator (which compiles it into a flow).

This module ships inside the AgentCore code bundle, so it must import with only
pydantic available — no boto3, no twilio, no fastapi.
"""

from __future__ import annotations

import os
import re
from pathlib import Path
from typing import Annotated, Literal, Union
from urllib.parse import urlencode

from pydantic import BaseModel, ConfigDict, Field, field_validator, model_validator

CONFIG_FILENAME = "ivr-config.json"

#: Intent key reserved for the required fallback destination.
FALLBACK_KEY = "fallback"

E164_PATTERN = r"^\+[1-9]\d{1,14}$"
SIP_URI_PATTERN = r"^sips?:[^\s@]+@[^\s]+$"
SIP_HEADER_KEY_PATTERN = r"^X-[A-Za-z0-9-]+$"
EXTENSION_PATTERN = r"^[0-9*#]{1,20}$"
INTENT_KEY_PATTERN = r"^[a-z0-9][a-z0-9_]{0,30}$"
PHONE_NUMBER_SID_PATTERN = r"^PN[0-9a-fA-F]{32}$"


class PhoneDestination(BaseModel):
    """A PSTN number, optionally followed by DTMF digits for an extension."""

    type: Literal["phone"] = "phone"
    number: str = Field(..., pattern=E164_PATTERN)
    extension: str | None = Field(default=None, pattern=EXTENSION_PATTERN)
    extension_pause_seconds: float = Field(
        default=2.0, ge=0, le=10, alias="extensionPauseSeconds"
    )

    model_config = ConfigDict(populate_by_name=True)

    @property
    def send_digits(self) -> str | None:
        """DTMF string for ``<Number sendDigits>``, or None if there is no extension.

        Each ``w`` is a half-second pause, so the configured pause in seconds
        becomes twice as many ``w`` characters.
        """
        if self.extension is None:
            return None
        return "w" * round(self.extension_pause_seconds * 2) + self.extension


class SipDestination(BaseModel):
    """A SIP endpoint, with optional custom headers and digest credentials."""

    type: Literal["sip"] = "sip"
    uri: str = Field(..., pattern=SIP_URI_PATTERN)
    headers: dict[str, str] = Field(default_factory=dict)
    username: str | None = None
    password: str | None = None

    model_config = ConfigDict(populate_by_name=True)

    @field_validator("headers")
    @classmethod
    def _validate_header_keys(cls, value: dict[str, str]) -> dict[str, str]:
        for key in value:
            if not re.match(SIP_HEADER_KEY_PATTERN, key):
                raise ValueError(
                    f"SIP header {key!r} is invalid: Twilio requires custom headers to "
                    f"start with 'X-' and match {SIP_HEADER_KEY_PATTERN}"
                )
        return value

    @property
    def dial_target(self) -> str:
        """The SIP URI with any custom headers appended as URL-encoded parameters."""
        if not self.headers:
            return self.uri
        separator = "&" if "?" in self.uri else "?"
        return f"{self.uri}{separator}{urlencode(self.headers)}"


class ClientDestination(BaseModel):
    """A Twilio Voice SDK client identity."""

    type: Literal["client"] = "client"
    identity: str = Field(..., min_length=1, max_length=121)

    model_config = ConfigDict(populate_by_name=True)


Destination = Annotated[
    Union[PhoneDestination, SipDestination, ClientDestination],
    Field(discriminator="type"),
]


class Business(BaseModel):
    """Customer-supplied description of the business, fed into the system prompt."""

    name: str = Field(..., min_length=1, max_length=100)
    prompt: str = Field(..., min_length=1, max_length=4000)
    greeting: str = Field(..., min_length=1, max_length=500)

    model_config = ConfigDict(populate_by_name=True)


class VoiceSettings(BaseModel):
    """ConversationRelay speech settings.

    Every field is optional and omitted from the generated widget when unset, so
    Twilio's own defaults apply rather than values hardcoded here.
    """

    language: str | None = None
    tts_provider: str | None = Field(default=None, alias="ttsProvider")
    voice: str | None = None
    transcription_provider: str | None = Field(default=None, alias="transcriptionProvider")
    speech_model: str | None = Field(default=None, alias="speechModel")

    model_config = ConfigDict(populate_by_name=True)


class Intent(BaseModel):
    """One routable caller intent and where it should be transferred."""

    key: str = Field(..., pattern=INTENT_KEY_PATTERN)
    name: str = Field(..., min_length=1, max_length=60)
    description: str = Field(..., min_length=1, max_length=200)
    destination: Destination

    model_config = ConfigDict(populate_by_name=True)

    @field_validator("key")
    @classmethod
    def _reject_reserved_key(cls, value: str) -> str:
        if value == FALLBACK_KEY:
            raise ValueError(
                f"intent key {value!r} is reserved for the fallback destination"
            )
        return value


class Fallback(BaseModel):
    """Required destination for callers the agent cannot classify."""

    name: str = Field(default="Operator", min_length=1, max_length=60)
    description: str = Field(
        default="Anything that does not match another option, or the caller asks "
        "for a person.",
        min_length=1,
        max_length=200,
    )
    destination: Destination

    model_config = ConfigDict(populate_by_name=True)


class TwilioSettings(BaseModel):
    """The Twilio resources this IVR is attached to."""

    phone_number: str = Field(..., pattern=E164_PATTERN, alias="phoneNumber")
    phone_number_sid: str = Field(
        ..., pattern=PHONE_NUMBER_SID_PATTERN, alias="phoneNumberSid"
    )
    conversation_configuration_id: str = Field(
        ..., min_length=1, alias="conversationConfigurationId"
    )

    model_config = ConfigDict(populate_by_name=True)


class IVRConfig(BaseModel):
    """Everything needed to build the agent prompt, the Studio flow, and the Lambda map."""

    version: Literal[1] = 1
    business: Business
    voice: VoiceSettings = Field(default_factory=VoiceSettings)
    intents: list[Intent] = Field(..., min_length=1)
    fallback: Fallback
    twilio: TwilioSettings

    model_config = ConfigDict(populate_by_name=True)

    @model_validator(mode="after")
    def _validate_unique_intent_keys(self) -> IVRConfig:
        keys = [intent.key for intent in self.intents]
        duplicates = sorted({key for key in keys if keys.count(key) > 1})
        if duplicates:
            raise ValueError(f"duplicate intent keys: {duplicates}")
        return self

    @property
    def intent_keys(self) -> list[str]:
        """Configured intent keys, excluding the fallback."""
        return [intent.key for intent in self.intents]

    def extension_destinations(self) -> dict[str, dict[str, str]]:
        """Destinations needing DTMF, keyed by intent, for the Lambda ``/dial`` route.

        Studio's Connect Call To widget cannot send digits, so only these
        destinations are routed through Lambda-generated TwiML.
        """
        result: dict[str, dict[str, str]] = {}
        candidates: list[tuple[str, Destination]] = [
            (intent.key, intent.destination) for intent in self.intents
        ]
        candidates.append((FALLBACK_KEY, self.fallback.destination))

        for key, destination in candidates:
            if isinstance(destination, PhoneDestination):
                send_digits = destination.send_digits
                if send_digits:
                    result[key] = {"number": destination.number, "sendDigits": send_digits}
        return result


def config_search_paths() -> list[Path]:
    """Candidate locations for ``ivr-config.json``, most specific first.

    Inside the AgentCore bundle the file sits next to this module. When the
    wizard or the Studio generator import this module from the repo, the file
    sits one level up at the example root.
    """
    paths: list[Path] = []
    override = os.environ.get("IVR_CONFIG_PATH")
    if override:
        paths.append(Path(override))
    module_dir = Path(__file__).resolve().parent
    paths.append(module_dir / CONFIG_FILENAME)
    paths.append(module_dir.parent / CONFIG_FILENAME)
    return paths


def load_config(path: str | Path | None = None) -> IVRConfig:
    """Load and validate the IVR configuration.

    Args:
        path: Explicit path to a config file. When omitted, the locations from
            :func:`config_search_paths` are tried in order.

    Returns:
        The validated configuration.

    Raises:
        FileNotFoundError: If no config file exists at any candidate location.
        pydantic.ValidationError: If the file exists but is invalid.
    """
    candidates = [Path(path)] if path is not None else config_search_paths()
    for candidate in candidates:
        if candidate.is_file():
            return IVRConfig.model_validate_json(candidate.read_text(encoding="utf-8"))

    searched = ", ".join(str(candidate) for candidate in candidates)
    raise FileNotFoundError(
        f"No {CONFIG_FILENAME} found. Searched: {searched}. "
        f"Run 'make configure' in deploy/agentcore_aws_lambda to create one."
    )
```

"""System prompt assembly for the IVR agent.

The voice prompt turns the agent into a triage attendant whose only job is to
pick one configured destination and call ``transfer_call``. The SMS prompt shares
the same business context but has no transfer tool, so it points callers at the
phone number instead.
"""

from __future__ import annotations

from ivr_config import FALLBACK_KEY, IVRConfig

VOICE_RULES = """\
You are the automated phone attendant for {business_name}.

Your only job is to work out which department the caller needs, then transfer them.

How to speak:
- One or two short sentences per turn. This is a phone call, not a chat window.
- Never use markdown, asterisks, bullet points, or emoji. Everything you say is read aloud.
- Ask at most one question per turn.

How to route:
- Match the caller to exactly one option from the list below.
- Once you know the option, say one short sentence naming where you are sending them, then \
call the transfer_call tool in the same turn. Do not ask the caller to confirm first.
- If the caller is vague, ask one clarifying question. If you still cannot tell after two \
attempts, transfer to {fallback_name}.
- If the caller asks for a person, a manager, or an operator, transfer to {fallback_name} \
straight away.
- Never invent a department that is not listed, and never promise a callback or anything \
else you cannot do.
- Do not try to solve the caller's problem, quote prices, or give policy details. Route them.
"""

SMS_RULES = """\

    lines.append(
        f"- {FALLBACK_KEY}: {config.fallback.name} — {config.fallback.description}"

    return f"About {config.business.name}:\n{config.business.prompt}"

```python
"""The transfer tool that hands a caller off to a configured destination.

Setting ``session.pending_handoff_data`` is TAC's supported hook for a custom
handoff (see ``tac/tools/handoff.py``): the voice channel sends the
ConversationRelay ``end`` message carrying this payload *after* the agent's final
response has been spoken, so the caller hears "connecting you to Billing" and
then gets transferred. The Studio flow splits on the slug.
"""

from __future__ import annotations

from typing import Any, Literal

from tac.models.handoff import PendingHandoffData
from tac.models.session import ConversationSession

from ivr_config import FALLBACK_KEY


def create_transfer_tool(session: ConversationSession, intent_keys: list[str]) -> Any:
    """Create a Strands tool that transfers the caller to a configured destination.

    Args:
        session: The live conversation session for this call. This is the same
            object TAC's voice channel reads when deciding whether to send the
            ConversationRelay ``end`` message, so mutating it here is what
            triggers the transfer.
        intent_keys: Configured intent keys, excluding the fallback.

    Returns:
        A Strands ``DecoratedFunctionTool`` named ``transfer_call``, ready for an
        agent's ``tools`` list.
    """
    from strands import tool

    allowed = tuple([*intent_keys, FALLBACK_KEY])

    def transfer_call(intent: str) -> dict[str, str]:
        """Transfers the caller to the department that handles the given intent.

        Call this as soon as you know where the caller belongs. Say one short
        sentence naming the destination in the same turn — the caller hears it
        before the transfer happens.

        Args:
            intent: Which configured destination to transfer the caller to.

        Returns:
            Dictionary with the transfer status and the resolved intent.
        """
        if intent not in allowed:
            raise ValueError(
                f"Unknown intent {intent!r}. Must be one of: {', '.join(allowed)}"
            )

        session.pending_handoff_data = PendingHandoffData(handoff_data=intent)
        return {"status": "transfer_initiated", "intent": intent}

    # Narrow the annotation to the configured keys so the generated tool schema
    # carries an enum. Strands builds inputSchema from the type hints, so this
    # must happen before decorating.
    transfer_call.__annotations__["intent"] = Literal[allowed]  # type: ignore[valid-type]

    return tool(transfer_call)
```

```python
"""Probe the Studio Flows API for the ConversationRelay widget's type string.

Uses POST /v2/Flows/Validate, which checks a definition against the real schema
without creating a flow, so this is free to run repeatedly.

Usage, from deploy/agentcore_aws_lambda with credentials in .env:

    python -m studio.discover
"""

from __future__ import annotations

import os
import sys
from typing import Any

from twilio.base.exceptions import TwilioRestException
from twilio.rest import Client

from .widgets import CR_WIDGET_TYPE_CANDIDATES


def candidate_definition(widget_type: str) -> dict[str, Any]:
    """A minimal two-state flow using ``widget_type`` for the relay widget."""
    return {
        "description": "ConversationRelay widget type probe",
        "initial_state": "Trigger",
        "flags": {"allow_concurrent_calls": True},
        "states": [
            {
                "name": "Trigger",
                "type": "trigger",
                "transitions": [{"event": "incomingCall", "next": "probe"}],
                "properties": {"offset": {"x": 0, "y": 0}},
            },
            {
                "name": "probe",
                "type": widget_type,
                "transitions": [{"event": "success"}, {"event": "failed"}],
                "properties": {
                    "url": "wss://example.com/relay",
                    "offset": {"x": 0, "y": 200},
                },
            },
        ],
    }


def probe_widget_type(client: Client, candidates: tuple[str, ...]) -> str | None:
    """Return the first candidate type the Flows API accepts, or None."""
    for candidate in candidates:
        try:
            result = client.studio.v2.flow_validate.update(
                friendly_name="conversationrelay-type-probe",
                status="draft",
                definition=candidate_definition(candidate),
            )
        except TwilioRestException as error:
            print(f"  {candidate}: rejected ({error.status} {error.msg})")
            continue

        if result.valid:
            print(f"  {candidate}: ACCEPTED")
            return candidate
        print(f"  {candidate}: rejected (valid=false)")
    return None


def main() -> int:
    account_sid = os.environ.get("TWILIO_ACCOUNT_SID")
    api_key = os.environ.get("TWILIO_API_KEY")
    api_secret = os.environ.get("TWILIO_API_SECRET")
    if not (account_sid and api_key and api_secret):
        print(
            "Set TWILIO_ACCOUNT_SID, TWILIO_API_KEY and TWILIO_API_SECRET "
            "(source your .env first).",
            file=sys.stderr,
        )
        return 2

    client = Client(api_key, api_secret, account_sid)

    print("Probing ConversationRelay widget type...")
    found = probe_widget_type(client, CR_WIDGET_TYPE_CANDIDATES)
    if not found:
        print(
            "\nNone of the candidates were accepted. Build a ConversationRelay "
            "widget in the Studio Console, then run:\n"
            "  twilio api:studio:v2:flows:fetch --sid FWxxxx -o json\n"
            "and read the widget's 'type' out of the definition.",
            file=sys.stderr,
        )
        return 1

    print(f"\nSet CR_WIDGET_TYPE = {found!r} in studio/widgets.py")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

## Task 6: Studio flow builder

Compiles an `IVRConfig` into a Studio flow definition. Pure function, no network, so it is
fully snapshot-testable.

Two behaviors worth understanding before you write it:

**Why `callCompleted` needs a split.** The Connect Call To widget's `callCompleted` transition
fires whether the far end answered and hung up normally *or* was busy, rejected, or never
answered. Routing it straight to a "sorry, we could not connect you" message would play that
message after successful calls too. So each dial widget's `callCompleted` goes to a
per-destination `split-based-on` that checks `DialCallStatus`: `completed` ends the flow,
anything else reaches a shared `say_no_answer`.

**Why extension destinations end the flow.** They use TwiML Redirect, and per Twilio's docs a
flow can only regain control of a voice call if the redirected TwiML appends
`FlowEvent=return` to a redirect back to the flow's webhook. The Lambda returns a bare
`<Dial>`, so control does not come back — `timeout` is set to `0` to say so explicitly, and
these destinations get no `DialCallStatus` check. This asymmetry is inherent to the mechanism,
not an oversight.

```python
"""Compile an IVR config into a Twilio Studio flow definition.

Pure: no network, no credentials, no clock. Everything here is a function of the
config plus the deployed Lambda URL and session token, which is what makes the
generated flow snapshot-testable.

Flow shape:

    Trigger (incomingCall)
      -> get_session      fetch the AgentCore presigned wss URL from Lambda
      -> ai_agent         ConversationRelay against that URL
      -> route_intent     split on the HandoffData slug
      -> dial_<key>       connect-call-to, or add-twiml-redirect for extensions
      -> check_<key>      only for connect-call-to: was it actually answered?
      -> say_no_answer    shared apology for unanswered destinations
"""

from __future__ import annotations

import json
from typing import Any

from ivr_config import (
    FALLBACK_KEY,
    ClientDestination,
    Destination,
    IVRConfig,
    PhoneDestination,
    SipDestination,
)

from .widgets import (
    CONNECT_CALL_TYPE,
    CR_URL_PROPERTY,
    CR_VOICE_PROPERTY_MAP,
    CR_WIDGET_TYPE,
    HTTP_REQUEST_TYPE,
    SAY_PLAY_TYPE,
    SPLIT_TYPE,
    TRIGGER_TYPE,
    TWIML_REDIRECT_TYPE,
)

TRIGGER_STATE = "Trigger"
SESSION_STATE = "get_session"
RELAY_STATE = "ai_agent"
ROUTE_STATE = "route_intent"
NO_ANSWER_STATE = "say_no_answer"

#: Liquid expression exposing the slug the agent sent in its end message.
HANDOFF_DATA = f"{{{{widgets.{RELAY_STATE}.HandoffData}}}}"

#: Caller ID for outbound legs: the number the caller originally dialed.
CALLER_ID = "{{contact.channel.address}}"

DIAL_TIMEOUT_SECONDS = 30

NO_ANSWER_MESSAGE = (
    "Sorry, no one is available to take your call right now. Please try again later."
)

# Canvas layout. Studio does not care, but a customer opening the flow does.
_COLUMN_WIDTH = 260
_FIRST_COLUMN_X = -260
_DIAL_ROW_Y = 850
_CHECK_ROW_Y = 1050


def dial_state_name(key: str) -> str:
    """Widget name for the destination belonging to ``key``."""
    return f"dial_{key}"


def check_state_name(key: str) -> str:
    """Widget name for the dial-status check belonging to ``key``."""
    return f"check_{key}"


def flow_friendly_name(config: IVRConfig) -> str:
    """Friendly name used to find and update this flow idempotently."""
    return f"TAC AI IVR — {config.business.name}"


def _equal_to(value: str, argument: str, label: str) -> dict[str, Any]:
    return {
        "friendly_name": label,
        "arguments": [argument],
        "type": "equal_to",
        "value": value,
    }


def _trigger_state() -> dict[str, Any]:
    """Entry point.

    Only ``incomingCall`` is wired. SMS reaches the agent through Conversation
    Orchestrator and the Lambda ``/webhook`` route, not through this flow.
    """
    return {
        "name": TRIGGER_STATE,
        "type": TRIGGER_TYPE,
        "transitions": [
            {"event": "incomingCall", "next": SESSION_STATE},
            {"event": "incomingMessage"},
            {"event": "incomingConversationMessage"},
            {"event": "incomingRequest"},
            {"event": "incomingParent"},
        ],
        "properties": {"offset": {"x": 0, "y": 0}},
    }


def _session_state(lambda_url: str, session_token: str) -> dict[str, Any]:
    """Fetch the AgentCore presigned WebSocket URL for this call.

    Studio's HTTP Request widget cannot send custom headers, so the shared token
    travels in the JSON body and the Lambda compares it in constant time.
    """
    body = json.dumps({"CallSid": "{{trigger.call.CallSid}}", "Token": session_token})
    return {
        "name": SESSION_STATE,
        "type": HTTP_REQUEST_TYPE,
        "transitions": [
            {"event": "success", "next": RELAY_STATE},
            {"event": "failed", "next": dial_state_name(FALLBACK_KEY)},
        ],
        "properties": {
            "method": "POST",
            "content_type": "application/json;charset=utf-8",
            "url": f"{lambda_url.rstrip('/')}/session",
            "body": body,
            "offset": {"x": 150, "y": 220},
        },
    }


def _relay_state(config: IVRConfig) -> dict[str, Any]:
    """Run ConversationRelay against the URL the session widget returned.

    ``welcome_greeting`` is deliberately absent: TACAgentCoreWebSocketAdapter
    sends the greeting on the setup message, and setting both would greet twice.
    """
    properties: dict[str, Any] = {
        CR_URL_PROPERTY: f"{{{{widgets.{SESSION_STATE}.parsed.websocket_url}}}}",
        "offset": {"x": 150, "y": 440},
    }
    for field_name, property_name in CR_VOICE_PROPERTY_MAP.items():
        value = getattr(config.voice, field_name, None)
        if value:
            properties[property_name] = value

    return {
        "name": RELAY_STATE,
        "type": CR_WIDGET_TYPE,
        "transitions": [
            {"event": "success", "next": ROUTE_STATE},
            {"event": "failed", "next": dial_state_name(FALLBACK_KEY)},
        ],
        "properties": properties,
    }


def _route_state(config: IVRConfig) -> dict[str, Any]:
    """Split on the handoff slug.

    Emits an explicit ``fallback`` branch as well as ``noMatch``: the agent can
    name the fallback deliberately when a caller asks for a person, and an empty
    or unrecognized slug lands in the same place.
    """
    transitions: list[dict[str, Any]] = [
        {"event": "noMatch", "next": dial_state_name(FALLBACK_KEY)}
    ]
    for key in [*config.intent_keys, FALLBACK_KEY]:
        transitions.append(
            {
                "event": "match",
                "next": dial_state_name(key),
                "conditions": [_equal_to(key, HANDOFF_DATA, f"HandoffData is {key}")],
            }
        )

    return {
        "name": ROUTE_STATE,
        "type": SPLIT_TYPE,
        "transitions": transitions,
        "properties": {"input": HANDOFF_DATA, "offset": {"x": 150, "y": 660}},
    }


def _connect_call_state(
    key: str, destination: Destination, offset: dict[str, int]
) -> dict[str, Any]:
    """Bridge the caller to a destination using Studio's native dial widget."""
    properties: dict[str, Any] = {
        "caller_id": CALLER_ID,
        "timeout": DIAL_TIMEOUT_SECONDS,
        "offset": offset,
    }

    if isinstance(destination, PhoneDestination):
        properties["noun"] = "number"
        properties["to"] = destination.number
    elif isinstance(destination, SipDestination):
        properties["noun"] = "sip"
        properties["to"] = destination.dial_target
        if destination.username:
            properties["sip_username"] = destination.username
        if destination.password:
            properties["sip_password"] = destination.password
    elif isinstance(destination, ClientDestination):
        properties["noun"] = "client"
        properties["to"] = destination.identity
    else:  # pragma: no cover - the discriminated union makes this unreachable
        raise TypeError(f"Unsupported destination type: {type(destination).__name__}")

    return {
        "name": dial_state_name(key),
        "type": CONNECT_CALL_TYPE,
        "transitions": [
            {"event": "callCompleted", "next": check_state_name(key)},
            {"event": "hangup"},
        ],
        "properties": properties,
    }


def _dial_check_state(key: str, offset: dict[str, int]) -> dict[str, Any]:
    """Distinguish "answered then ended" from "busy, rejected, or never answered".

    Connect Call To fires ``callCompleted`` for both, so without this the apology
    would play after successful calls too.
    """
    status = f"{{{{widgets.{dial_state_name(key)}.DialCallStatus}}}}"
    return {
        "name": check_state_name(key),
        "type": SPLIT_TYPE,
        "transitions": [
            {"event": "noMatch", "next": NO_ANSWER_STATE},
            {
                "event": "match",
                "conditions": [_equal_to("completed", status, "Answered and completed")],
            },
        ],
        "properties": {"input": status, "offset": offset},
    }


def _twiml_redirect_state(
    key: str, lambda_url: str, offset: dict[str, int]
) -> dict[str, Any]:
    """Hand the call to Lambda-generated TwiML so an extension can be dialed.

    Studio's dial widget has no sendDigits. ``timeout: 0`` declares that control
    will not return to the flow — the Lambda returns a bare ``<Dial>``, and per
    Twilio's docs a flow can only regain a voice call if the TwiML redirects back
    with ``FlowEvent=return``.
    """
    return {
        "name": dial_state_name(key),
        "type": TWIML_REDIRECT_TYPE,
        "transitions": [
            {"event": "return"},
            {"event": "timeout"},
            {"event": "failed"},
        ],
        "properties": {
            "url": f"{lambda_url.rstrip('/')}/dial?intent={key}",
            "method": "POST",
            "timeout": 0,
            "offset": offset,
        },
    }


def _no_answer_state(offset: dict[str, int]) -> dict[str, Any]:
    """Shared apology for destinations that did not pick up."""
    return {
        "name": NO_ANSWER_STATE,
        "type": SAY_PLAY_TYPE,
        "transitions": [{"event": "audioComplete"}],
        "properties": {"say": NO_ANSWER_MESSAGE, "loop": 1, "offset": offset},
    }


def _destination_states(config: IVRConfig, lambda_url: str) -> list[dict[str, Any]]:
    """One dial widget per intent plus the fallback, with status checks where possible."""
    targets: list[tuple[str, Destination]] = [
        (intent.key, intent.destination) for intent in config.intents
    ]
    targets.append((FALLBACK_KEY, config.fallback.destination))

    states: list[dict[str, Any]] = []
    for index, (key, destination) in enumerate(targets):
        column_x = _FIRST_COLUMN_X + _COLUMN_WIDTH * index
        needs_dtmf = (
            isinstance(destination, PhoneDestination) and destination.send_digits is not None
        )
        if needs_dtmf:
            states.append(
                _twiml_redirect_state(key, lambda_url, {"x": column_x, "y": _DIAL_ROW_Y})
            )
        else:
            states.append(
                _connect_call_state(key, destination, {"x": column_x, "y": _DIAL_ROW_Y})
            )
            states.append(
                _dial_check_state(key, {"x": column_x, "y": _CHECK_ROW_Y})
            )
    return states


def build_flow_definition(
    config: IVRConfig, lambda_url: str, session_token: str
) -> dict[str, Any]:
    """Build the Studio flow definition for this IVR.

    Args:
        config: Validated IVR configuration.
        lambda_url: Base URL of the deployed Lambda function URL, with or without
            a trailing slash.
        session_token: Shared secret the ``/session`` route checks.

    Returns:
        A flow definition ready to pass as the ``Definition`` parameter of the
        Studio Flows API.
    """
    states: list[dict[str, Any]] = [
        _trigger_state(),
        _session_state(lambda_url, session_token),
        _relay_state(config),
        _route_state(config),
    ]
    states.extend(_destination_states(config, lambda_url))
    states.append(_no_answer_state({"x": 150, "y": 1250}))

    return {
        "description": f"AI IVR for {config.business.name}",
        "initial_state": TRIGGER_STATE,
        "flags": {"allow_concurrent_calls": True},
        "states": states,
    }
```

## Task 7: Lambda `/session` and `/dial` routes

Both new routes are handled in the example's `index.py` **before** delegating to
`proxy.lambda_handler`. That ordering is load-bearing: `AgentCoreLambdaProxy.lambda_handler`
validates a Twilio signature on every path (`src/tac_aws/proxy/agentcore_lambda.py:104-110`),
and Studio's HTTP Request widget cannot send one.

Auth differs per route, deliberately:

- **`/session`** is called by Studio's HTTP Request widget, which supports no custom headers
  and sends no Twilio signature. It authenticates with a shared token compared using
  `hmac.compare_digest`. The token is visible to anyone who can read the flow in the Console;
  all it yields is a presigned WebSocket URL scoped to one call session.
- **`/dial`** is fetched by Twilio Voice, not by Studio — the TwiML Redirect widget makes
  Studio *print* TwiML instructing Twilio to request the URL. That request carries
  `X-Twilio-Signature`, so it is validated with `TwilioSignatureValidator`, which already
  folds `rawQueryString` into the signed URL (needed here because the intent travels as a
  query parameter).

- Create: `deploy/agentcore_aws_lambda/lambda/routes.py`
- Modify: `deploy/agentcore_aws_lambda/lambda/index.py` (full rewrite)

**Interfaces:**
- Consumes: `TwilioSignatureValidator` from `tac_aws.proxy`.
- Produces:

```python
"""IVR-specific Lambda routes.

``/session`` mints the AgentCore presigned WebSocket URL for a call, because
Studio cannot sign an AWS request itself. ``/dial`` returns TwiML for
destinations that need DTMF, because Studio's Connect Call To widget has no
sendDigits.

Both are written as plain functions taking their dependencies as arguments so
they can be tested without AWS or Twilio.
"""

from __future__ import annotations

import base64
import binascii
import hmac
import json
from typing import Any, Callable, Protocol
from xml.sax.saxutils import quoteattr

from tac.core.logging import get_logger

logger = get_logger(__name__)

SESSION_PATH = "/session"
DIAL_PATH = "/dial"

UNAVAILABLE_MESSAGE = (
    "Sorry, that option is not available right now. Please call again later."
)


class SignatureValidator(Protocol):
    """The slice of TwilioSignatureValidator these routes depend on."""

    def validate(self, event: dict[str, Any]) -> bool: ...


def json_response(status: int, payload: dict[str, Any]) -> dict[str, Any]:
    """Build a Lambda Function URL JSON response."""
    return {
        "statusCode": status,
        "headers": {"Content-Type": "application/json"},
        "body": json.dumps(payload),
    }


def twiml_response(twiml: str) -> dict[str, Any]:
    """Build a Lambda Function URL TwiML response."""
    return {
        "statusCode": 200,
        "headers": {"Content-Type": "application/xml"},
        "body": twiml,
    }


def _request_method(event: dict[str, Any]) -> str:
    context = event.get("requestContext") or {}
    http = context.get("http") or {}
    return str(http.get("method", "")).upper()


def _decode_body(event: dict[str, Any]) -> str | None:
    """Return the request body as text, or None if it cannot be decoded."""
    body: str = event.get("body") or ""
    if not body:
        return ""
    if event.get("isBase64Encoded"):
        try:
            return base64.b64decode(body).decode("utf-8")
        except (TypeError, binascii.Error, UnicodeDecodeError) as error:
            logger.warning(f"Failed to decode request body: {error}")
            return None
    return body


def extract_call_sid(event: dict[str, Any]) -> str | None:
    """Pull ``CallSid`` out of a JSON request body."""
    body = _decode_body(event)
    if not body:
        return None
    try:
        parsed = json.loads(body)
    except (TypeError, json.JSONDecodeError):
        return None
    if not isinstance(parsed, dict):
        return None
    call_sid = parsed.get("CallSid")
    return call_sid if isinstance(call_sid, str) and call_sid else None


def _submitted_token(event: dict[str, Any]) -> str:
    body = _decode_body(event)
    if not body:
        return ""
    try:
        parsed = json.loads(body)
    except (TypeError, json.JSONDecodeError):
        return ""
    if not isinstance(parsed, dict):
        return ""
    token = parsed.get("Token")
    return token if isinstance(token, str) else ""


def handle_session(
    event: dict[str, Any],
    *,
    expected_token: str,
    presign: Callable[[str], str],
) -> dict[str, Any]:
    """Mint a presigned AgentCore WebSocket URL for the call in this request.

    Args:
        event: Lambda Function URL event.
        expected_token: The shared token embedded in the Studio flow.
        presign: Callable taking a CallSid and returning a ``wss://`` URL.

    Returns:
        A Lambda response. 200 with ``{"websocket_url": ...}`` on success; 403 on
        a bad token, 405 on a non-POST, 400 on a malformed body, 500 if the
        deployment has no token configured or presigning fails.
    """
    if _request_method(event) != "POST":
        return json_response(405, {"error": "Method not allowed"})

    if not expected_token:
        logger.error("IVR_SESSION_TOKEN is not configured; refusing to mint session URLs")
        return json_response(500, {"error": "Server misconfigured"})

    if not hmac.compare_digest(_submitted_token(event), expected_token):
        logger.warning("Rejected /session request with an invalid token")
        return json_response(403, {"error": "Forbidden"})

    call_sid = extract_call_sid(event)
    if not call_sid:
        return json_response(400, {"error": "Missing CallSid"})

    try:
        websocket_url = presign(call_sid)
    except Exception as error:
        logger.error(f"Failed to presign AgentCore URL: {error}", exc_info=True)
        return json_response(500, {"error": "Internal server error"})

    return json_response(200, {"websocket_url": websocket_url})


def _hangup_twiml(message: str) -> str:
    return (
        '<?xml version="1.0" encoding="UTF-8"?>'
        f"<Response><Say>{message}</Say><Hangup/></Response>"
    )


def _dial_twiml(number: str, send_digits: str) -> str:
    return (
        '<?xml version="1.0" encoding="UTF-8"?>'
        "<Response><Dial>"
        f"<Number sendDigits={quoteattr(send_digits)}>{_escape_text(number)}</Number>"
        "</Dial></Response>"
    )


def _escape_text(value: str) -> str:
    return value.replace("&", "&amp;").replace("<", "&lt;").replace(">", "&gt;")


def handle_dial(
    event: dict[str, Any],
    *,
    destinations: dict[str, dict[str, str]],
    validator: SignatureValidator,
) -> dict[str, Any]:
    """Return TwiML dialing a destination that needs DTMF digits.

    Args:
        event: Lambda Function URL event, fetched by Twilio Voice and therefore
            carrying ``X-Twilio-Signature``.
        destinations: Map of intent key to ``{"number": ..., "sendDigits": ...}``.
        validator: Twilio signature validator.

    Returns:
        A Lambda response. 200 with ``<Dial>`` TwiML on success, 200 with a spoken
        apology and ``<Hangup/>`` for an unknown intent, 403 on a bad signature.
        Never 500 into a live call.
    """
    if not validator.validate(event):
        return json_response(403, {"error": "Invalid webhook signature"})

    parameters = event.get("queryStringParameters") or {}
    intent = parameters.get("intent")

    destination = destinations.get(intent) if intent else None
    if destination is None:
        logger.warning(f"No extension destination configured for intent {intent!r}")
        return twiml_response(_hangup_twiml(UNAVAILABLE_MESSAGE))

    return twiml_response(_dial_twiml(destination["number"], destination["sendDigits"]))
```

## Task 8: Capture-rule preflight

the IVR number, because Studio's ConversationRelay widget cannot set
`conversationConfiguration`. Without the rule, TAC's `_initialize_conversation` polls

```python
"""Verify the Conversation Orchestrator capture rules the voice path depends on.

Studio's ConversationRelay widget cannot set ``conversationConfiguration``, so
Orchestrator has to capture traffic for the IVR number passively. If it does not,
TAC's voice channel polls for a conversation keyed on the CallSid, gives up after
about 3.75 seconds, and the caller silently drops through to the operator.

Checking at deploy time turns that into an actionable error.
"""

from __future__ import annotations

from typing import TYPE_CHECKING, Iterable

from ivr_config import IVRConfig

if TYPE_CHECKING:
    from tac.models.conversation import (
        CaptureRule,
        ChannelSettings,
        ConversationConfiguration,
    )

REQUIRED_CHANNELS = ("VOICE", "SMS")

WILDCARD = "*"


def rule_matches(rule: CaptureRule, number: str) -> bool:
    """True if ``rule`` captures traffic addressed to ``number``."""
    return rule.to_address in (number, WILDCARD)


def find_channel_settings(
    channel_settings: dict[str, ChannelSettings] | None, channel: str
) -> ChannelSettings | None:
    """Look up a channel's settings, ignoring key casing."""
    if not channel_settings:
        return None
    for key, settings in channel_settings.items():
        if key.upper() == channel.upper():
            return settings
    return None


def check_capture_rules(
    configuration: ConversationConfiguration,
    number: str,
    channels: Iterable[str] = REQUIRED_CHANNELS,
) -> list[str]:
    """Return one problem string per channel missing a matching capture rule.

    Args:
        configuration: The Conversation Orchestrator configuration to inspect.
        number: The IVR phone number in E.164.
        channels: Channels that must capture traffic for this number.

    Returns:
        Human-readable problems. Empty means the configuration is healthy.
    """
    problems: list[str] = []
    for channel in channels:
        settings = find_channel_settings(configuration.channel_settings, channel)
        rules = settings.capture_rules if settings else None
        if not rules:
            problems.append(
                f"{channel} has no capture rules, so Conversation Orchestrator will "
                f"not create conversations for {number}."
            )
            continue
        if not any(rule_matches(rule, number) for rule in rules):
            configured = ", ".join(rule.to_address for rule in rules) or "none"
            problems.append(
                f"{channel} has capture rules, but none match {number} "
                f"(configured destinations: {configured})."
            )
    return problems


def format_problems(problems: list[str], config: IVRConfig) -> str:
    """Turn problems into a message that says exactly what to fix."""
    bullets = "\n".join(f"  - {problem}" for problem in problems)
    return (
        "Conversation Orchestrator is not capturing traffic for this IVR:\n"
        f"{bullets}\n\n"
        "Fix it in the Twilio Console:\n"
        f"  1. Open Conversation Orchestrator configuration "
        f"{config.twilio.conversation_configuration_id}.\n"
        "  2. Go to the Channel Traffic tab.\n"
        "  3. Under 'Automatically captured traffic', add "
        f"{config.twilio.phone_number} for both Voice and Messaging.\n\n"
        "Or run 'make capture-rules' to add them for you.\n\n"
        "Why this matters: the Studio ConversationRelay widget cannot set "
        "conversationConfiguration, so passive capture is what creates the "
        "conversation TAC looks up by CallSid. Without it every call falls through "
        "to the fallback destination."
    )


def fetch_configuration(config: IVRConfig) -> ConversationConfiguration:
    """Read the Orchestrator configuration this IVR points at.

    Builds a TAC instance from the environment because TAC's Orchestrator client
    is the only reader for the Control Plane configuration endpoint in this repo.

    Raises:
        RuntimeError: If credentials are missing or Orchestrator is unavailable.
    """
    from tac import TAC
    from tac.core.config import TACConfig

    account_sid = os.environ.get("TWILIO_ACCOUNT_SID")
    api_key = os.environ.get("TWILIO_API_KEY")
    api_secret = os.environ.get("TWILIO_API_SECRET")
    if not (account_sid and api_key and api_secret):
        raise RuntimeError(
            "Set TWILIO_ACCOUNT_SID, TWILIO_API_KEY and TWILIO_API_SECRET."
        )

    tac = TAC(
        config=TACConfig(
            account_sid=account_sid,
            auth_token=os.environ.get("TWILIO_AUTH_TOKEN", ""),
            api_key=api_key,
            api_secret=api_secret,
            phone_number=config.twilio.phone_number,
            conversation_configuration_id=config.twilio.conversation_configuration_id,
        )
    )
    orchestrator = tac.conversation_orchestrator_client
    if orchestrator is None:
        raise RuntimeError("Conversation Orchestrator client is unavailable.")

    return orchestrator.get_configuration(config.twilio.conversation_configuration_id)


def run_check(config: IVRConfig) -> list[str]:
    """Fetch the configuration and check it. Returns problems, empty when healthy."""
    return check_capture_rules(fetch_configuration(config), config.twilio.phone_number)


def main() -> int:
    """CLI entry point for ``make preflight``."""
    config = load_config()
    print("Checking Conversation Orchestrator capture rules...")
    try:
        problems = run_check(config)
    except Exception as error:
        print(f"  Could not read the configuration: {error}", file=sys.stderr)
        return 1

    if problems:
        print(format_problems(problems, config), file=sys.stderr)
        return 1

    print(f"  OK: traffic for {config.twilio.phone_number} is captured.")
    return 0


if __name__ == "__main__":

"""Create or update the IVR's Studio flow and point the phone number at it.

Idempotent: the flow is found by friendly name, so re-running after a config
change updates the existing flow rather than piling up duplicates.

Usage, from the repository root with the example's .env exported:

    PYTHONPATH=deploy/agentcore_aws_lambda uv run python -m studio.provision
"""

from __future__ import annotations

import os
import subprocess
import sys
from typing import Any

from ivr_config import load_config
from twilio.base.exceptions import TwilioRestException
from twilio.rest import Client

from .flow_builder import build_flow_definition, flow_friendly_name
from .preflight import format_problems, run_check

COMMIT_MESSAGE = "Generated by tac_aws AI IVR (make deploy)"

LAMBDA_STACK_NAME = "TacLambdaStack"
LAMBDA_URL_OUTPUT_KEYS = ("VoiceWebhookUrl", "ConversationWebhookUrl")


def find_flow_by_name(client: Any, friendly_name: str) -> Any | None:
    """Return the flow with this friendly name, or None."""
    for flow in client.studio.v2.flows.list():
        if flow.friendly_name == friendly_name:
            return flow
    return None


def upsert_flow(client: Any, friendly_name: str, definition: dict[str, Any]) -> Any:
    """Create the flow, or update it in place if it already exists. Always published."""
    existing = find_flow_by_name(client, friendly_name)
    if existing is not None:
        return client.studio.v2.flows(existing.sid).update(
            friendly_name=friendly_name,
            status="published",
            definition=definition,
            commit_message=COMMIT_MESSAGE,
        )

    return client.studio.v2.flows.create(
        friendly_name=friendly_name,
        status="published",
        definition=definition,
        commit_message=COMMIT_MESSAGE,
    )


def attach_number(client: Any, phone_number_sid: str, webhook_url: str) -> None:
    """Point the number's voice webhook at the flow."""
    client.incoming_phone_numbers(phone_number_sid).update(
        voice_url=webhook_url, voice_method="POST"
    )


def lambda_url_from_env() -> str:
    """Resolve the deployed Lambda Function URL base.

    Prefers IVR_LAMBDA_URL when set. Otherwise reads it from the CloudFormation
    stack output and strips the trailing path, since the stack publishes full
    endpoint URLs rather than the base.
    """
    explicit = os.environ.get("IVR_LAMBDA_URL")
    if explicit:
        return explicit.rstrip("/")

    for output_key in LAMBDA_URL_OUTPUT_KEYS:
        command = [
            "aws",
            "cloudformation",
            "describe-stacks",
            "--stack-name",
            LAMBDA_STACK_NAME,
            "--query",
            f"Stacks[0].Outputs[?OutputKey=='{output_key}'].OutputValue",
            "--output",
            "text",
        ]
        result = subprocess.run(command, capture_output=True, text=True, check=False)
        value = result.stdout.strip()
        if result.returncode == 0 and value and value != "None":
            # Outputs look like https://xxx.lambda-url.region.on.aws/twiml
            return value.rstrip("/").rsplit("/", 1)[0]

    raise RuntimeError(
        f"Could not resolve the Lambda Function URL from stack {LAMBDA_STACK_NAME}. "
        "Deploy the stacks first, or set IVR_LAMBDA_URL."
    )


def main() -> int:
    account_sid = os.environ.get("TWILIO_ACCOUNT_SID")
    api_key = os.environ.get("TWILIO_API_KEY")
    api_secret = os.environ.get("TWILIO_API_SECRET")
    session_token = os.environ.get("IVR_SESSION_TOKEN")

    if not (account_sid and api_key and api_secret):
        print(
            "Set TWILIO_ACCOUNT_SID, TWILIO_API_KEY and TWILIO_API_SECRET.", file=sys.stderr
        )
        return 2
    if not session_token:
        print(
            "IVR_SESSION_TOKEN is not set. Run 'make configure' to generate one.",
            file=sys.stderr,
        )
        return 2

    config = load_config()
    client = Client(api_key, api_secret, account_sid)

    print("Checking Conversation Orchestrator capture rules...")
    try:
        problems = run_check(config)
    except Exception as error:
        print(f"  Could not read the configuration: {error}", file=sys.stderr)
        return 1

    if problems:
        print(format_problems(problems, config), file=sys.stderr)
        return 1
    print("  Capture rules OK.")

    lambda_url = lambda_url_from_env()
    print(f"Using Lambda URL: {lambda_url}")

    definition = build_flow_definition(config, lambda_url, session_token)
    friendly_name = flow_friendly_name(config)

    print("Validating the flow definition...")
    validation = client.studio.v2.flow_validate.update(
        friendly_name=friendly_name, status="published", definition=definition
    )
    if not validation.valid:
        print("  Studio rejected the definition.", file=sys.stderr)
        return 1
    print("  Valid.")

    print(f"Publishing flow {friendly_name!r}...")
    try:
        flow = upsert_flow(client, friendly_name, definition)
    except TwilioRestException as error:
        print(f"  Failed: {error.status} {error.msg}", file=sys.stderr)
        return 1
    print(f"  Flow SID: {flow.sid}")

    print(f"Pointing {config.twilio.phone_number} at the flow...")
    attach_number(client, config.twilio.phone_number_sid, flow.webhook_url)
    print("  Done.")

    print(
        f"\nIVR live on {config.twilio.phone_number}\n"
        f"  Console: https://console.twilio.com/us1/develop/studio/flows/{flow.sid}"
    )
    return 0


if __name__ == "__main__":
    raise SystemExit(main())

"""Best-effort helper that adds the Orchestrator capture rules the IVR needs.

TAC's Orchestrator client is read-only for configurations, so this writes through
the Control Plane API directly. The exact write contract is not documented in this
repo, so every failure path falls back to printing the Console steps rather than
pretending the rules were added. The Task 8 preflight is the real enforcement.

Usage, from the repository root with the example's .env exported:

    PYTHONPATH=deploy/agentcore_aws_lambda uv run python -m studio.capture_rules
"""

from __future__ import annotations

import os
import sys
from typing import Any

import httpx
from ivr_config import load_config

from .preflight import REQUIRED_CHANNELS, format_problems

CONTROL_PLANE_BASE = "https://conversations.twilio.com/v2/ControlPlane/Configurations"


def add_capture_rules(
    configuration: dict[str, Any], number: str, channels: tuple[str, ...] = REQUIRED_CHANNELS
) -> dict[str, Any]:
    """Return a copy of the raw configuration with a capture rule per channel.

    Existing rules are preserved; a rule for ``number`` is appended only where one
    is not already present.
    """
    updated = dict(configuration)
    channel_settings = dict(updated.get("channelSettings") or {})

    for channel in channels:
        existing_key = next(
            (key for key in channel_settings if key.upper() == channel.upper()), channel
        )
        settings = dict(channel_settings.get(existing_key) or {})
        rules = list(settings.get("captureRules") or [])
        if not any(rule.get("to") in (number, "*") for rule in rules):
            rules.append({"from": "*", "to": number})
        settings["captureRules"] = rules
        channel_settings[existing_key] = settings

    updated["channelSettings"] = channel_settings
    return updated


def main() -> int:
    api_key = os.environ.get("TWILIO_API_KEY")
    api_secret = os.environ.get("TWILIO_API_SECRET")
    if not (api_key and api_secret):
        print("Set TWILIO_API_KEY and TWILIO_API_SECRET.", file=sys.stderr)
        return 2

    config = load_config()
    configuration_id = config.twilio.conversation_configuration_id
    url = f"{CONTROL_PLANE_BASE}/{configuration_id}"
    auth = (api_key, api_secret)

    with httpx.Client(auth=auth, timeout=30.0, follow_redirects=True) as client:
        fetched = client.get(url)
        if fetched.status_code != 200:
            print(f"Could not read {configuration_id}: {fetched.status_code}", file=sys.stderr)
            print(format_problems(["Unable to read the configuration"], config), file=sys.stderr)
            return 1

        payload = add_capture_rules(fetched.json(), config.twilio.phone_number)
        written = client.put(url, json=payload)

    if written.status_code not in (200, 201, 204):
        print(
            f"Could not update {configuration_id}: {written.status_code} {written.text}",
            file=sys.stderr,
        )
        print(
            format_problems(
                ["Automatic capture-rule setup failed; add them by hand"], config
            ),
            file=sys.stderr,
        )
        return 1

    print(f"Capture rules added for {config.twilio.phone_number}.")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

## Task 10: Wizard backend

A local FastAPI app bound to `127.0.0.1`, started by `make configure`. It reads the Twilio
account to populate dropdowns, validates the submitted config with the Task 1 model, and writes
`ivr-config.json` plus `.env`.

Design points:

- **No server-side session.** `POST /api/resources` takes credentials in the body and returns
  numbers and configurations in one shot. Nothing is cached between requests.

- **`GET /api/config` strips secrets.** The page shows `•••• set` for credentials rather than
  echoing them back into HTML.
- **Conversation Orchestrator configurations** are listed with a direct call to

  because TAC's client exposes `get_configuration` but no list method.

"""Write the wizard's output: ivr-config.json and .env."""

from __future__ import annotations

import secrets
from pathlib import Path

from ivr_config import CONFIG_FILENAME, IVRConfig

ENV_FILENAME = ".env"

REDACTED = "•••• set"

#: Keys never echoed back to the browser.
SECRET_ENV_KEYS = {
    "TWILIO_AUTH_TOKEN",
    "TWILIO_API_SECRET",
    "IVR_SESSION_TOKEN",
}


def generate_session_token() -> str:
    """A fresh shared secret for the Lambda ``/session`` route."""
    return secrets.token_urlsafe(32)


def existing_env_values(text: str) -> dict[str, str]:
    """Parse ``KEY=value`` pairs from a .env file, ignoring comments and junk."""
    values: dict[str, str] = {}
    for line in text.splitlines():
        stripped = line.strip()
        if not stripped or stripped.startswith("#") or "=" not in stripped:
            continue
        key, _, value = stripped.partition("=")
        values[key.strip()] = value.strip()
    return values


def merge_env(existing: str, updates: dict[str, str]) -> str:
    """Apply ``updates`` to a .env file's text, preserving everything else.

    Keys already present are rewritten in place so ordering and surrounding
    comments survive. Keys not present are appended.
    """
    remaining = dict(updates)
    lines = existing.splitlines()
    merged: list[str] = []

    for line in lines:
        stripped = line.strip()
        if stripped and not stripped.startswith("#") and "=" in stripped:
            key = stripped.partition("=")[0].strip()
            if key in remaining:
                merged.append(f"{key}={remaining.pop(key)}")
                continue
        merged.append(line)

    for key, value in remaining.items():
        merged.append(f"{key}={value}")

    return "\n".join(merged).rstrip("\n") + "\n"


def redact(values: dict[str, str], secret_keys: set[str]) -> dict[str, str]:
    """Replace set secrets with a placeholder and drop unset ones entirely."""
    result: dict[str, str] = {}
    for key, value in values.items():
        if key in secret_keys:
            if value:
                result[key] = REDACTED
            continue
        result[key] = value
    return result


def write_config(config: IVRConfig, example_root: Path) -> Path:
    """Write ``ivr-config.json`` using JSON aliases, and return its path."""
    target = example_root / CONFIG_FILENAME
    target.write_text(
        config.model_dump_json(by_alias=True, indent=2, exclude_none=True) + "\n",
        encoding="utf-8",
    )
    return target


def write_env(updates: dict[str, str], example_root: Path) -> Path:
    """Merge ``updates`` into the example's .env, creating it if needed."""
    target = example_root / ENV_FILENAME
    existing = target.read_text(encoding="utf-8") if target.is_file() else ""
    target.write_text(merge_env(existing, updates), encoding="utf-8")
    return target
```

"""Read the customer's Twilio account to populate the wizard's dropdowns.

Nothing here creates or modifies Twilio resources.
"""

from __future__ import annotations

from typing import Any

import httpx
from pydantic import BaseModel, Field
from twilio.rest import Client

CONTROL_PLANE_CONFIGURATIONS = (
    "https://conversations.twilio.com/v2/ControlPlane/Configurations"
)

REQUEST_TIMEOUT_SECONDS = 30.0


class TwilioCredentials(BaseModel):
    """Credentials submitted by the wizard form."""

    account_sid: str = Field(..., alias="accountSid", min_length=34, max_length=34)
    auth_token: str = Field(..., alias="authToken", min_length=1)
    api_key: str = Field(..., alias="apiKey", min_length=34, max_length=34)
    api_secret: str = Field(..., alias="apiSecret", min_length=1)

    model_config = {"populate_by_name": True}


def _client(credentials: TwilioCredentials) -> Client:
    return Client(
        credentials.api_key, credentials.api_secret, credentials.account_sid
    )


def verify(credentials: TwilioCredentials) -> str:
    """Confirm the credentials work and return the account's friendly name."""
    account = _client(credentials).api.v2010.accounts(credentials.account_sid).fetch()
    return str(account.friendly_name)


def _supports_voice(number: Any) -> bool:
    """True unless the number explicitly lacks voice capability.

    The SDK annotates ``capabilities`` as ``Optional[str]`` but populates it
    straight from the JSON payload, where it is an object such as
    ``{"voice": true, "sms": true}``. Anything unexpected is treated as capable,
    so a usable number is never hidden from the wizard.
    """
    capabilities = getattr(number, "capabilities", None)
    if isinstance(capabilities, dict):
        return bool(capabilities.get("voice", True))
    return True


def list_phone_numbers(credentials: TwilioCredentials) -> list[dict[str, str]]:
    """Voice-capable numbers on the account."""
    numbers = _client(credentials).incoming_phone_numbers.list(limit=200)
    return [
        {
            "sid": number.sid,
            "phoneNumber": number.phone_number,
            "friendlyName": number.friendly_name or number.phone_number,
        }
        for number in numbers
        if _supports_voice(number)
    ]


def list_conversation_configurations(
    credentials: TwilioCredentials,
) -> list[dict[str, str]]:
    """Conversation Orchestrator configurations on the account.

    TAC's client can fetch one configuration but cannot list them, so this calls
    the Control Plane API directly with API key basic auth.
    """
    auth = (credentials.api_key, credentials.api_secret)
    with httpx.Client(auth=auth, timeout=REQUEST_TIMEOUT_SECONDS, follow_redirects=True) as client:
        response = client.get(CONTROL_PLANE_CONFIGURATIONS)
        response.raise_for_status()
        payload = response.json()

    items = payload.get("configurations") or payload.get("items") or []
    return [
        {
            "id": item.get("id", ""),
            "displayName": item.get("displayName") or item.get("description") or item.get("id", ""),
        }
        for item in items
        if item.get("id")
    ]
```

```python
"""Local FastAPI app backing the IVR configuration page.

Bound to 127.0.0.1 by ``make configure``. Holds no session state: the browser
sends credentials with each request that needs them, and nothing is cached.
"""

from __future__ import annotations

from pathlib import Path
from typing import Any

from fastapi import FastAPI, HTTPException
from fastapi.responses import FileResponse
from fastapi.staticfiles import StaticFiles
from ivr_config import CONFIG_FILENAME, IVRConfig
from pydantic import BaseModel, Field, ValidationError

from .twilio_lookup import (
    TwilioCredentials,
    list_conversation_configurations,
    list_phone_numbers,
    verify,
)
from .writer import (
    ENV_FILENAME,
    SECRET_ENV_KEYS,
    existing_env_values,
    generate_session_token,
    redact,
    write_config,
    write_env,
)

STATIC_DIR = Path(__file__).resolve().parent / "static"

NEXT_COMMAND = "cd deploy/agentcore_aws_lambda && make deploy"


class AwsSettings(BaseModel):
    """AWS deployment target, written to .env for the Makefile and CDK."""

    profile: str = Field(..., min_length=1)
    account_id: str = Field(..., alias="accountId", pattern=r"^\d{12}$")
    region: str = Field(..., alias="region", min_length=1)

    model_config = {"populate_by_name": True}


class SaveRequest(BaseModel):
    """Everything the page submits when the user clicks Save."""

    credentials: TwilioCredentials
    aws: AwsSettings
    config: dict[str, Any]


def _env_updates(request: SaveRequest, config: IVRConfig, session_token: str) -> dict[str, str]:
    return {
        "AWS_PROFILE": request.aws.profile,
        "AWS_ACCOUNT_ID": request.aws.account_id,
        "AWS_REGION": request.aws.region,
        "TWILIO_ACCOUNT_SID": request.credentials.account_sid,
        "TWILIO_AUTH_TOKEN": request.credentials.auth_token,
        "TWILIO_API_KEY": request.credentials.api_key,
        "TWILIO_API_SECRET": request.credentials.api_secret,
        "TWILIO_PHONE_NUMBER": config.twilio.phone_number,
        "TWILIO_CONVERSATION_CONFIGURATION_ID": config.twilio.conversation_configuration_id,
        "IVR_SESSION_TOKEN": session_token,
    }


def create_app(example_root: Path) -> FastAPI:
    """Build the wizard app rooted at ``example_root``.

    Args:
        example_root: Directory holding ``.env`` and ``ivr-config.json`` — normally
            ``deploy/agentcore_aws_lambda``. Parameterized so tests use tmp_path.
    """
    app = FastAPI(title="TAC AI IVR configuration", docs_url=None, redoc_url=None)

    if STATIC_DIR.is_dir():
        app.mount("/static", StaticFiles(directory=STATIC_DIR), name="static")

    @app.get("/")
    def index() -> FileResponse:
        return FileResponse(STATIC_DIR / "index.html")

    @app.get("/api/config")
    def get_config() -> dict[str, Any]:
        """Return the saved config plus non-secret .env values, for re-editing."""
        config_path = example_root / CONFIG_FILENAME
        env_path = example_root / ENV_FILENAME

        config: dict[str, Any] | None = None
        if config_path.is_file():
            try:
                config = IVRConfig.model_validate_json(
                    config_path.read_text(encoding="utf-8")
                ).model_dump(by_alias=True, exclude_none=True)
            except ValidationError:
                config = None

        env_values: dict[str, str] = {}
        if env_path.is_file():
            env_values = existing_env_values(env_path.read_text(encoding="utf-8"))

        return {"config": config, "env": redact(env_values, SECRET_ENV_KEYS)}

    @app.post("/api/resources")
    def resources(credentials: TwilioCredentials) -> dict[str, Any]:
        """Verify credentials and list the numbers and configurations to choose from."""
        try:
            account_name = verify(credentials)
            numbers = list_phone_numbers(credentials)
            configurations = list_conversation_configurations(credentials)
        except Exception as error:
            raise HTTPException(status_code=400, detail=str(error)) from error

        return {
            "accountName": account_name,
            "phoneNumbers": numbers,
            "conversationConfigurations": configurations,
        }

    @app.post("/api/config")
    def save_config(request: SaveRequest) -> dict[str, Any]:
        """Validate and write ivr-config.json and .env."""
        try:
            config = IVRConfig.model_validate(request.config)
        except ValidationError as error:
            raise HTTPException(status_code=422, detail=error.errors()) from error

        env_path = example_root / ENV_FILENAME
        current = (
            existing_env_values(env_path.read_text(encoding="utf-8"))
            if env_path.is_file()
            else {}
        )
        session_token = current.get("IVR_SESSION_TOKEN") or generate_session_token()

        config_path = write_config(config, example_root)
        written_env = write_env(_env_updates(request, config, session_token), example_root)

        return {
            "written": [str(config_path), str(written_env)],
            "nextCommand": NEXT_COMMAND,
        }

    return app
```

Behaviors that matter:

- Starts with **two** intent rows. `+ Add intent` appends one; the ✕ is disabled when only one
  remains, so the config can never become empty.
- `key` is auto-slugged from the name (lowercase, non-alphanumerics to `_`, trimmed to 31

  flow route on. If a slug collides or is empty, the row shows an inline error.
- The destination radio swaps which fields are visible; only the active type's fields are
  submitted.
- The fallback section reuses the same destination editor markup as intent rows and cannot be
  removed.
- Save posts `{credentials, aws, config}`. A 422 renders Pydantic's field errors next to the
  offending inputs by walking the `loc` path; anything else shows a banner.
- On load, `GET /api/config` repopulates every non-secret field. Credential inputs show
  `•••• set` as a placeholder when already configured, and are only submitted if retyped —
  which means an unchanged save needs the credentials re-entered. State that in the UI copy

"use strict";

const form = document.getElementById("ivr-form");
const intentList = document.getElementById("intent-list");
const banner = document.getElementById("banner");

/** Turn an intent name into the slug the agent and Studio flow route on. */
function slugify(name) {
  return name
    .toLowerCase()
    .replace(/[^a-z0-9]+/g, "_")
    .replace(/^_+|_+$/g, "")
    .slice(0, 31);
}

function show(element, message) {
  element.textContent = message;
  element.hidden = !message;
}

function clearErrors() {
  form.querySelectorAll(".error").forEach((node) => {
    node.textContent = "";
    node.hidden = true;
  });
  banner.hidden = true;
}

/** Build a destination editor from the shared template. */
function makeDestinationEditor() {
  const fragment = document
    .getElementById("destination-fields")
    .content.cloneNode(true);
  const fieldset = fragment.querySelector("fieldset");
  const groupName = `destinationType-${Math.random().toString(36).slice(2)}`;

  fieldset.querySelectorAll('input[name="destinationType"]').forEach((radio) => {
    radio.name = groupName;
    radio.addEventListener("change", () => {
      fieldset.querySelectorAll("[data-fields]").forEach((block) => {
        block.hidden = block.dataset.fields !== radio.value;
      });
    });
  });

  return fieldset;
}

function selectedType(fieldset) {
  const checked = fieldset.querySelector("input[type=radio]:checked");
  return checked ? checked.value : "phone";
}

function value(fieldset, name) {
  const field = fieldset.querySelector(`[name="${name}"]`);
  return field ? field.value.trim() : "";
}

/** Parse "X-Name: value" lines into an object. Blank lines are ignored. */
function parseHeaders(text) {
  const headers = {};
  text
    .split("\n")
    .map((line) => line.trim())
    .filter(Boolean)
    .forEach((line) => {
      const separator = line.indexOf(":");
      if (separator > 0) {
        headers[line.slice(0, separator).trim()] = line.slice(separator + 1).trim();
      }
    });
  return headers;
}

/**
 * Read the active destination type's fields.
 *
 * Optional fields are omitted entirely rather than sent as "", so the Pydantic
 * model applies its own defaults instead of rejecting an empty string.
 */
function readDestination(fieldset) {
  const type = selectedType(fieldset);

  if (type === "phone") {
    const destination = { type: "phone", number: value(fieldset, "number") };
    const extension = value(fieldset, "extension");
    if (extension) {
      destination.extension = extension;
      const pause = value(fieldset, "extensionPauseSeconds");
      if (pause) {
        destination.extensionPauseSeconds = Number(pause);
      }
    }
    return destination;
  }

  if (type === "sip") {
    const destination = { type: "sip", uri: value(fieldset, "uri") };
    const headers = parseHeaders(value(fieldset, "headers"));
    if (Object.keys(headers).length) {
      destination.headers = headers;
    }
    const username = value(fieldset, "username");
    const password = value(fieldset, "password");
    if (username) destination.username = username;
    if (password) destination.password = password;
    return destination;
  }

  return { type: "client", identity: value(fieldset, "identity") };
}

function addIntentRow(data) {
  const fragment = document.getElementById("intent-row").content.cloneNode(true);
  const row = fragment.querySelector("li");
  const nameField = row.querySelector('[name="name"]');
  const slugNode = row.querySelector("[data-slug]");
  const editor = makeDestinationEditor();

  row.appendChild(editor);

  nameField.addEventListener("input", () => {
    slugNode.textContent = slugify(nameField.value) || "—";
  });

  row.querySelector(".remove").addEventListener("click", () => {
    row.remove();
    refreshRemoveButtons();
  });

  if (data) {
    nameField.value = data.name || "";
    row.querySelector('[name="description"]').value = data.description || "";
    slugNode.textContent = data.key || slugify(nameField.value) || "—";
    applyDestination(editor, data.destination);
  }

  intentList.appendChild(row);
  refreshRemoveButtons();
  return row;
}

/** Never let the form reach zero intents — the config model requires at least one. */
function refreshRemoveButtons() {
  const rows = intentList.querySelectorAll("li.intent");
  rows.forEach((row) => {
    row.querySelector(".remove").disabled = rows.length <= 1;
  });
}

function applyDestination(fieldset, destination) {
  if (!destination) return;

  const radio = fieldset.querySelector(`input[value="${destination.type}"]`);
  if (radio) {
    radio.checked = true;
    radio.dispatchEvent(new Event("change"));
  }

  const setField = (name, fieldValue) => {
    const field = fieldset.querySelector(`[name="${name}"]`);
    if (field && fieldValue !== undefined && fieldValue !== null) {
      field.value = fieldValue;
    }
  };

  setField("number", destination.number);
  setField("extension", destination.extension);
  setField("extensionPauseSeconds", destination.extensionPauseSeconds);
  setField("uri", destination.uri);
  setField("username", destination.username);
  setField("identity", destination.identity);

  if (destination.headers) {
    setField(
      "headers",
      Object.entries(destination.headers)
        .map(([key, headerValue]) => `${key}: ${headerValue}`)
        .join("\n")
    );
  }
}

function field(name) {
  return form.elements.namedItem(name);
}

function collectConfig() {
  const voice = {};
  const language = field("language").value;
  const voiceName = field("voice").value.trim();
  if (language) voice.language = language;
  if (voiceName) voice.voice = voiceName;

  const numberSelect = field("phoneNumberSid");
  const selectedOption = numberSelect.options[numberSelect.selectedIndex];

  const intents = Array.from(intentList.querySelectorAll("li.intent")).map((row) => {
    const name = row.querySelector('[name="name"]').value.trim();
    return {
      key: slugify(name),
      name,
      description: row.querySelector('[name="description"]').value.trim(),
      destination: readDestination(row.querySelector("fieldset.destination")),
    };
  });

  return {
    version: 1,
    business: {
      name: field("businessName").value.trim(),
      prompt: field("businessPrompt").value.trim(),
      greeting: field("greeting").value.trim(),
    },
    voice,
    intents,
    fallback: {
      name: field("fallbackName").value.trim(),
      description: field("fallbackDescription").value.trim(),
      destination: readDestination(
        document.querySelector("#fallback-destination fieldset.destination")
      ),
    },
    twilio: {
      phoneNumber: selectedOption ? selectedOption.dataset.number : "",
      phoneNumberSid: numberSelect.value,
      conversationConfigurationId: field("conversationConfigurationId").value,
    },
  };
}

function credentialsPayload() {
  return {
    accountSid: field("accountSid").value.trim(),
    authToken: field("authToken").value.trim(),
    apiKey: field("apiKey").value.trim(),
    apiSecret: field("apiSecret").value.trim(),
  };
}

/**
 * Render Pydantic errors next to the field that caused them.
 *
 * `loc` looks like ["body","config","intents",0,"destination","number"]. Anything
 * that cannot be mapped to an input goes to the banner so no error is swallowed.
 */
function showFieldErrors(errors) {
  const unmapped = [];

  errors.forEach((error) => {
    const path = (error.loc || []).filter(
      (part) => part !== "body" && part !== "config"
    );
    const message = error.msg || "Invalid value";

    if (path[0] === "intents" && typeof path[1] === "number") {
      const row = intentList.querySelectorAll("li.intent")[path[1]];
      if (row) {
        const target = path.includes("destination")
          ? row.querySelector('[data-error="destination"]')
          : row.querySelector('[data-error="row"]');
        show(target, `${path.slice(2).join(".")}: ${message}`);
        return;
      }
    }

    if (path[0] === "intents") {
      show(document.getElementById("intents-error"), message);
      return;
    }
    if (path[0] === "business") {
      show(document.getElementById("business-error"), `${path.join(".")}: ${message}`);
      return;
    }
    if (path[0] === "fallback") {
      show(document.getElementById("fallback-error"), `${path.join(".")}: ${message}`);
      return;
    }
    if (path[0] === "twilio") {
      show(document.getElementById("resources-error"), `${path.join(".")}: ${message}`);
      return;
    }
    if (path[0] === "credentials" || path[0] === "aws") {
      show(document.getElementById("credentials-error"), `${path.join(".")}: ${message}`);
      return;
    }

    unmapped.push(`${path.join(".")}: ${message}`);
  });

  if (unmapped.length) {
    show(banner, unmapped.join(" · "));
  }
}

async function save(event) {

## Task 12: CDK wiring

Passes the IVR session token and the extension destination map into the Lambda. The token comes
from `.env`; the destination map is derived from `ivr-config.json` so it cannot drift from what
the Studio flow expects.

**Files:**
- Modify: `deploy/agentcore_aws_lambda/cdk/config/env-config.ts`
- Modify: `deploy/agentcore_aws_lambda/cdk/lib/lambda-stack.ts`
- Modify: `deploy/agentcore_aws_lambda/cdk/bin/app.ts`

**Interfaces:**
- Consumes: `ivr-config.json` (Task 1 schema), `.env`.
- Produces: `TacEnvConfig.ivrSessionToken: string`, `TacEnvConfig.ivrExtensionDestinations: string`.

- [ ] **Step 1: Extend the env config loader**

In `deploy/agentcore_aws_lambda/cdk/config/env-config.ts`, add the two fields to
`TacEnvConfig`, add `IVR_SESSION_TOKEN` to `requiredVars`, and derive the destination map by
reading `ivr-config.json`:

The map is **not** recomputed here. `IVRConfig.extension_destinations()` (Task 1) already
produces it, and reimplementing the `sendDigits` rule in TypeScript would be a silent
correctness trap: Python's `round()` uses banker's rounding (`round(2.5) == 2`) while JS
`Math.round(2.5) == 3`, so a fractional `extensionPauseSeconds` would make the Lambda send
different DTMF than the model says. Instead `make build` writes
`agent/ivr-extension-destinations.json` from Python (Task 13) and the CDK just reads it.

```typescript
import * as fs from 'fs';

export interface TacEnvConfig {
  // AWS Configuration
  awsAccountId: string;
  awsRegion: string;
  // Twilio Configuration (non-secret)
  twilioPhoneNumber: string;
  twilioConversationConfigurationId: string;
  // AI IVR
  ivrSessionToken: string;
  /** JSON map of intent key -> {number, sendDigits}, for the Lambda /dial route. */
  ivrExtensionDestinations: string;
}

/**
 * Read the intent -> {number, sendDigits} map the Lambda /dial route serves.
 *
 * Generated by 'make build' from ivr-config.json via
 * IVRConfig.extension_destinations(), so Python owns the sendDigits rule and
 * there is exactly one implementation of it.
 */
function loadExtensionDestinations(configRoot: string): string {
  const generatedPath = path.resolve(
    configRoot,
    '../agent/ivr-extension-destinations.json'
  );
  if (!fs.existsSync(generatedPath)) {
    throw new Error(
      `Missing ${generatedPath}. Run 'make build' (or 'make deploy') to generate it.`
    );
  }

  // Re-serialize so the Lambda environment variable is compact and stable.
  return JSON.stringify(JSON.parse(fs.readFileSync(generatedPath, 'utf-8')));
}
```

## Deferred and explicitly out of scope

Do not build these without a new spec:

- Hosting the wizard anywhere but localhost.
- Buying phone numbers or creating Conversation Orchestrator configurations.
- Business hours, holiday schedules, queueing, or voicemail.
- Flex or TaskRouter handoff — destinations are dial targets.
- Any change to `src/tac_aws/`.
- Writing voice transcripts into Conversation Memory. This is a known consequence of using
  passive capture instead of `conversationConfiguration`: `VoiceChannel.send_response` only
  writes to the WebSocket, so the caller's utterances are not stored. Memory *retrieval* still
  works because the profile resolves from the caller's number.
